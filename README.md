# Tetris Crush

A fast-paced, colorful browser game that fuses the mechanics of Tetris (falling blocks, line-clearing) with Candy Crush (color-matching, combo explosions). 

![Tetris Crush Screenshot](screenshot.png)

## Features

- 🧩 Classic Tetris-style falling blocks
- 🍬 Candy Crush color-matching mechanics
- 💥 Explosive combo system with particle effects
- 🎮 Keyboard and touch controls for all devices
- 🎵 Built-in sound effects
- 🎯 Power-ups: bombs and color-wipe blocks
- 📱 Responsive design for desktop and mobile

## How to Play

### Controls
- **Arrow Keys:** Move and rotate blocks
- **Space:** Hard drop
- **P:** Pause/resume
- **Mobile:** Tap buttons or use swipe gestures

### Gameplay
1. Arrange falling blocks to create complete horizontal lines (Tetris style)
2. Match 3+ same-colored blocks in any pattern (Candy Crush style)
3. Activate special power-up blocks for explosive effects
4. Clear as many blocks as you can to increase your score
5. The game speeds up as your level increases

## Technology

Built with:
- HTML5 Canvas for rendering
- Vanilla JavaScript for game logic
- Tailwind CSS for styling UI elements

## Installation

No installation required! Simply open `index.html` in any modern browser to play.

```bash
# Clone the repository
git clone https://github.com/jeremymartinezq/Tetris-Crush-Game.git

# Open the index.html file in your browser
```

## Development

The game is structured into modular JavaScript files:

- `main.js` - Entry point and initialization
- `game.js` - Core game controller
- `board.js` - Game board logic and match detection
- `blocks.js` - Tetromino definitions and rendering
- `particles.js` - Particle system for visual effects
- `audio.js` - Sound effects and music
- `utils.js` - Utility functions
